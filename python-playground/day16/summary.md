# 第十六天学习总结模板

## 今天学了什么

- pytest 会自动收集以 `test_` 开头的测试函数。
- `TestClient` 不需要启动 uvicorn，也能向 FastAPI app 发送模拟 HTTP 请求。
- fixture 可以在每个测试前重置数据库，让测试互不依赖。

## TestClient 是什么

- `TestClient` 是 FastAPI 的测试客户端，可以调用 `get`、`post` 等方法模拟前端请求。
- 返回的 response 可以断言状态码和 JSON 内容。

## 手动测试和自动化测试的区别

- 手动测试：需要人在 `/docs` 或浏览器里逐个操作，适合临时观察，但速度慢且容易漏测。
- 自动化测试：把请求和预期结果写成代码，可以重复运行，适合修改代码后的回归检查。
